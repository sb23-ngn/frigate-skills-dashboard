FRIGATE TECHNICAL SKILLS DASHBOARD – MULTI-PAGE VERSION

Pages: index.html (Overview), skills.html, qualifications.html, projects.html, directory.html, explorer.html.

To run locally: open this folder in VS Code and use Live Server on index.html.

Upload the original Excel workbook once. The browser saves a local copy in localStorage so the workbook remains available while navigating between pages in the same browser on the same device. The workbook is not uploaded to GitHub or to a server. If browser storage is cleared or a different device/browser is used, upload the workbook again.

To publish: upload all files in this folder to the existing GitHub repository, replacing the old files. Do NOT upload the Excel workbook. GitHub Pages will serve index.html as the home page.

The project uses SheetJS and Chart.js from public CDNs, so an internet connection is required to load those libraries.
