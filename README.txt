FRIGATE TECHNICAL SKILLS DASHBOARD

WHAT THIS VERSION INCLUDES
- Employee names and employee IDs for identification.
- Job title, current/last project location and last project supervisor.
- Primary and additional skills/trades, competency level, technical activities.
- Equipment, tools, machinery and systems operated.
- Certificates, current/expired status and certification categories.
- Total experience, primary-trade experience, previous employers and technical experience.
- Linked project history: project, client, location, dates, role, responsibility, completion, tasks, equipment and supervisor.
- Searchable employee profiles, skill charts, project charts, skills data explorer and CSV export.

PRIVACY SCOPE
This version intentionally does NOT display or export contact addresses, phone numbers, email addresses, respondent emails, device information, survey start/submission timestamps, or other contact details. Names and employee IDs are retained as requested for identifying each employee's technical profile. The internal survey reference is used only to link project entries and is not shown.

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted personnel-dashboard-skills-only folder in VS Code.
3. Open index.html and click Go Live (Live Server).
4. In the browser, click Upload survey workbook.
5. Select the original Personnel_Skills_Experience_Certification_Survey_Report_2026-11-03.xlsx file.

The workbook is read in your browser. It is not sent to a server. Internet access is required to load the SheetJS and Chart.js libraries from their CDNs.
